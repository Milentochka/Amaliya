# Модуль 2. Страница мероприятия

## 1. Цель
Информационная страница для зарегистрированных гостей: вся информация о Крестинах и Банкете в одном месте + интерактив (RSVP, галерея, мини-игра, лидерборд). Содержимое доступно только авторизованным гостям и админу. Ключевые блоки также дублируются в ЛК гостя.

## 2. Доступ и роли
- **Гость:** видит страницу, заполняет RSVP в ЛК, играет в мини-игру, смотрит/лайкает/комментирует медиа, может загрузить видео-поздравление (на модерацию).
- **Админ:** управляет всем контентом через админку, модерирует гостевые видео, видит расширенный список гостей с пометками «сам/админ».

## 3. Структура страницы (сверху вниз)
1. Шапка с обратным отсчётом
2. Карточка «Крестины»
3. Карточка «Банкет»
4. Дресс-код
5. Пожелания семьи
6. Контакты родителей
7. Список гостей
8. Галерея фото/видео
9. Мини-игра «Ангел Амалия»
10. Лидерборд

## 4. Блоки страницы

### 4.1. Шапка
- Заголовок (например, «Приглашение к Амалии»)
- Изображение/иллюстрация
- **Обратный отсчёт** до даты Крестин — живой таймер (дни : часы : минуты)

### 4.2. Карточка «Крестины»
- Время начала
- Адрес (текст)
- Кнопка **«Открыть в Яндекс.Картах»** (внешняя ссылка)
- Программа — текстовое поле (markdown), что и когда происходит
- Индикатор RSVP-статуса текущего гостя на эту часть. Клик ведёт в ЛК на форму RSVP.

### 4.3. Карточка «Банкет»
То же, что 4.2.

### 4.4. Дресс-код
Свободный текстовый блок.

### 4.5. Пожелания семьи
Свободный текстовый блок.

### 4.6. Контакты родителей
Две карточки (мама, папа), каждая:
- Имя
- Фото
- Телефон (кликабельный — `tel:`)
- Telegram-ник (кликабельная ссылка `t.me/<ник>`)

### 4.7. Список гостей
- Сетка карточек: аватар (сказочный герой), имя, знак зодиака, год животного.
- Сортировка — по алфавиту.
- Поиск по имени (мгновенный, по подстроке).
- **Только в админке:** дополнительный значок у гостей, добавленных вручную админом.

### 4.8. Галерея фото/видео
- **Формат:** сетка миниатюр 4×5 (адаптивно сжимается под мобильную ширину). При клике — открывается лайтбокс с навигацией ←/→.
- **Лимиты для админа:** до 20 фото + 1–2 видео ≤3 мин.
- **Гостевые видео-поздравления:** кнопка «Добавить видео» открывает форму загрузки. Лимиты: ≤30 сек, ≤50 МБ. Загруженное видео — со статусом `pending`, ждёт модерации.
- **Модерация:** при загрузке гостевого видео админ получает TG-уведомление. В админке — очередь pending-видео с кнопками «Одобрить» / «Отклонить».
- **В лайтбоксе:**
  - Лайки — публичные (видно «лайкнули: Маша, Петя, …»).
  - Комментарии — под каждым медиа отдельно. Автор может редактировать и удалять свой коммент. Админ может удалять любые. Редактировать чужие нельзя.
  - Кнопка «Удалить» (для своих видео — гость, для всего — админ).

### 4.9. Мини-игра «Ангел Амалия»
- Кнопка «Сыграть» — открывает игру в модалке/полноэкранно.
- Под кнопкой — текущий накопленный счёт гостя + его место в рейтинге + сколько попыток осталось сегодня.
- Если cutoff наступил — кнопка неактивна с подписью «Игра завершена. Победитель: <Имя>».

### 4.10. Лидерборд
- Top-10 гостей по сумме очков.
- Колонки: место, аватар, имя, очки.
- Обновление: при перезагрузке страницы + раз в минуту фоном.
- В админке: полный список всех гостей с очками + кнопка «Объявить победителя» (доступна только после cutoff).

## 5. RSVP (в личном кабинете)

### 5.1. Карточка RSVP
Гость заполняет:
- **RSVP-Крестины:** Приду / Не приду / Возможно
- **RSVP-Банкет:** Приду / Не приду / Возможно
- **«Со мной придут»** (опционально, и только если RSVP ≠ «Не приду»):
  - Multi-select из списка зарегистрированных гостей.
  - Свободный текст для незарегистрированных (дети, неизвестные люди).

### 5.2. Логика «пары» (двусторонняя)
Когда гость A добавляет гостя B в multi-select «Со мной придут»:
1. Запись `pair_confirmed = null` (в ожидании).
2. B получает в TG: «<A> указал, что придёт с тобой на <часть>. Подтверждаешь?» с кнопками **«Да»** / **«Нет»**.
3. **Если B нажал «Да»** → `pair_confirmed = true`. A получает уведомление «<B> подтвердил».
4. **Если B нажал «Нет»** → `pair_confirmed = false`, запись удаляется из списка A. A получает уведомление «<B> опроверг».

### 5.3. Дедлайн
RSVP можно менять в любой момент (нет жёсткого дедлайна).

## 6. Telegram-уведомления

| Событие | Кому |
|---------|------|
| Гость задал/изменил RSVP | Самому себе (эхо) + «паре» (если затронуто) + админу |
| Гость A добавил B в «Со мной» | B (с кнопками подтвердить/опровергнуть) |
| B подтвердил/опроверг пару | A + админу |
| Гость загрузил видео на модерацию | Админу |
| Админ одобрил/отклонил видео | Гостю-загрузчику |
| Игра — попытка сыграна | Гостю (свой счёт + место в рейтинге) |
| Cutoff игры — победитель определён | Всем гостям |

## 7. Мини-игра «Ангел Амалия»

### 7.1. Механика — «Поймай падающее»
- Амалия — на нижней трети экрана, движется влево-вправо.
- Сверху падают объекты двух типов:
  - **Полезные** (поймать → +очки): бутылочка, соска, погремушка, мишка, подгузник, игрушка.
  - **Препятствия** (избегать → -жизнь): облако, туча, молния, чёрный ангел.
- При столкновении с препятствием — теряется жизнь. **3 жизни**, после потери всех — игра заканчивается досрочно.
- **Длительность:** таймер 60 сек. По истечении — игра останавливается, итоговый счёт записывается.

### 7.2. Управление
**Кнопки ← / → снизу экрана** (видны и на мобильном, и на десктопе). На десктопе дополнительно работают **стрелки клавиатуры**.

### 7.3. Графика
- **Амалия:** ангел-ребёнок ~1 год, белые крылья, белое платье, светло-русые волосы, **вид со спины**. Источник — готовая иллюстрация или нейросетевая картинка по описанию (фото Амалии не нужны — образ обобщённый).
- **Предметы и препятствия** — простые иллюстрации в едином стиле.
- **Фон** — небо с облаками.

### 7.4. Очки и лимиты
- Полезный предмет — например, **+10 очков** (значение настраивается на этапе реализации).
- Препятствие — **-1 жизнь** (без штрафа очков).
- **3 попытки в календарный день** (00:00–23:59 локального времени). Накопленный счёт = сумма очков всех попыток всех дней.
- **Cutoff:** 14:00 в день Крестин. После — кнопка «Сыграть» отключается, лидерборд фиксируется.

### 7.5. Хранение результатов
- Каждая попытка → запись в `game_attempt` (guest_id, score, played_at).
- Накопленный счёт = `SUM(score)` по гостю до cutoff.
- Лидерборд — кешируется на 30 сек (агрегация SUM).

## 8. Управление контентом (админ)

В админке раздел **«Мероприятие»** с подразделами:
- Шапка (фото + текст)
- Карточка Крестин (время, адрес, программа, ссылка на Яндекс.Карты)
- Карточка Банкета (то же)
- Дресс-код, Пожелания (текстовые поля)
- Родители (две карточки)
- Галерея (список + кнопка добавить + очередь модерации)
- Игра (вкл/выкл, дата cutoff)
- Лидерборд (только просмотр + «Объявить победителя» после cutoff)

## 10. Технический стек (дополнения)
- **Игра:** Phaser.js (или простой Canvas/JS) — встраивается в Next.js страницу.
- **Лидерборд:** агрегация `SUM` на бэке + кеш 30 сек.
- **Карта:** внешние ссылки на Яндекс.Карты (без встроенной карты).
- **Загрузка медиа:** клиентская валидация (длительность через HTML5 `video.duration`, размер через `file.size`) до отправки на бэк.
- **Уведомления RSVP/пары/игры:** все идут через Telegram-бота (aiogram).
